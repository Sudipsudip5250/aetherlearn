About this fallback

A quieter way to learn.

AetherLearn is a local-first learning project. This browser client shares the same Markdown lesson files as the native Android app, and keeps the web experience intentionally smaller.

Appearance

Light/dark and reading palettes stay in this browser. They do not require a network and do not upload a preference.

Offline-readyCache the 37 current lessons, then keep reading without a network.
Local-onlyProgress, notes, bookmarks, and quiz attempts remain in this browser.
Android bridgeTermux exercises are not available on the web and remain Android-only.

Browser data controls

These actions affect this browser origin only. Export creates a plain JSON copy; it is not an encrypted backup. Import validates the file and asks before replacing current learning data.

Optional visual pack

Thirty-seven small accessible diagrams and trace prompts are available as an optional local pack, one for each current lesson. Core lessons remain complete without them. This proof of concept stores the SVGs in this browser’s Cache Storage; browser quotas and eviction still apply.
